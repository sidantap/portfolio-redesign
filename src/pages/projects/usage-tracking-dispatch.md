## Usage tracking

I instrumented three internal tools, the CS Admin Report, Dispatch Shift Assignment and the DAT Portal, to log timestamp, user, action, record ID and context. Power BI views show how each tool is actually used over time.

## Live dispatch assignments

Separately, I embedded a Power App inside a Power BI report so dispatchers could change shift assignments and see the result immediately, without leaving the report.
